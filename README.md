# SportPulse News Website

A sports news website developed for the BAC Web & Multimedia Development (WMD) Year 1 Semester 2 Assignment.

## Pages (7 HTML files)

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with top stories |
| Football | `football.html` | Football news and league table |
| Basketball | `basketball.html` | NBA and basketball coverage |
| Tennis | `tennis.html` | Tennis and Grand Slam news |
| Athletics | `athletics.html` | Track and field news |
| About | `about.html` | Mission, team, and values |
| Feedback | `feedback.html` | Contact form with JS validation |

## Technologies

- HTML5
- CSS3 (external stylesheet: `css/style.css`)
- Bootstrap 5.3.2
- JavaScript (`js/main.js`, `js/validation.js`)

## Local Testing

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`

## GitHub Pages Deployment

1. Create a GitHub repository named with your SCIS number (e.g. `FCIPS21-014`)
2. Upload all files to the repository
3. Go to Settings → Pages → Source: Deploy from branch `main` / folder `/ (root)`
4. Your site will be available at: `https://[username].github.io/[repository]/`
